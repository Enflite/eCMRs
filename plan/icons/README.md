# Deck icons

White glyphs go on the red rounded badge (the standard slide header). The ink, red and green versions are for light backgrounds.

Each icon comes in four colors: `i<N>_white.png`, `i<N>_ink.png`, `i<N>_red.png`, `i<N>_green.png`.

| # | Glyph | Used for |
|---|---|---|
| 1 | Clipboard with check | BRD / requirements |
| 2 | Target | Scope |
| 3 | Tag | Field order / labels |
| 6 | Pencil and ruler | Design (one slide per UET form) |
| 7 | Wrench and screwdriver | Develop |
| 8 | Layers | TRN first, then production / Staging |
| 9 | Rocket | Launch / FormSync |
| 10 | Magnifier | Test |
| 11 | Gears | Optimize |

`scripts/new-project.sh` copies this folder to `plan/icons/` in a new project, and the logo to `plan/brand/`.
