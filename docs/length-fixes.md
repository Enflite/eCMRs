# eCMRs — SQL column and IDO property lengths

Generated by `scripts/compare_live_lengths.py` from the TRN exports [`ToExcel_SqlColumns_2026-09-29.csv`](reference/ToExcel_SqlColumns_2026-09-29.csv) and [`ToExcel_IdoProperties_2026-09-29.csv`](reference/ToExcel_IdoProperties_2026-09-29.csv), against the target schema in `scripts/generate_schema_csv.py`. Don't hand-edit: after the changes, export both grids again, save them here with the date, and re-run. Both tables should then be empty.

**Target**: every text column we own is `nvarchar(255)` - generous, no space padding, and still sortable and filterable in SyteLine grids (`nvarchar(max)` isn't everywhere). Columns using a SyteLine data type (`ItemType`, `DeptType`, `WcType`, `EmpNumType`, `UsernameType`, `DescriptionType`, `LongDescType`, `RevisionType`, `QCLongCharType`, `QCPriorityType`) keep that type's length: their values come from SyteLine and always fit. Every IDO property's **Length** equals its column's.
