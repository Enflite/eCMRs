eCMRs

Change Management Requests: create, track and close a CMR on one form.

Use this form to create, track and close a Change Management Request (CMR): a request to change a part, drawing, process, tooling, material or documentation. One CMR record holds everything from the request through Quality and Engineering review to Implementation and closing.

eCMRs replaces the Create Change Request, Change Request Management and QC CMRs forms. It is an Enflite form on its own table and IDO (ue_ecmrs); standard SyteLine forms and data are not changed.

Working a CMR

  1. Click New. The form fills in CMR Num (CMR-YYMMDD-HHMMSS), Create Date and Created By.
  2. Fill in the top of the form: PO, Item, Vendor, Priority and the Requested Action.
  3. Under Change Request Fields, pick the Dept, Work Center and Initial Change. The Requirement checkboxes are ticked for you; change them if needed.
  4. Quality and Engineering fill in their sections: codes, disposition, reviewer and RCA notes.
  5. Planning, Purchasing and CM tick their box when their part is done and pick a reviewer.
  6. Select Closed to close the CMR. Save after each step.

Header

Status
The stage the CMR is at in the change process.
Assigned
The employee the CMR is assigned to. The first box is the employee number; the second box shows the employee's name.
Notify
Shows a message only. No notification is sent from this button yet.
Help
Opens this eCMRs help: the form overview and a page for every field. Right-click a field and choose Help for Infor's QC CMRs help topic.
CMR Num
The CMR's unique number, in the form CMR-YYMMDD-HHMMSS: the date and time New was clicked (for example CMR-260929-111742). It can't be changed.
Create Date
The date the CMR was created.
Created By
The user who created the CMR.
PO Num
The purchase order the change relates to, if any. The list shows every purchase order line (PO, item and line); type to narrow it down.
PO Line
The line on the selected PO. The list shows only the lines of the PO in PO Num, with their item.
Assigned Buyer
The buyer responsible for the purchasing side of the change. Select an employee from the list; the employee number is stored.
Qty
The quantity affected by the change.
POC
The point of contact for this CMR.
RFQ Num
The request for quote number, if the change involves a quote.
Job Num
The job the change relates to, if any. The list shows job numbers from material transactions; type to narrow it down.
Drawing Revision
The drawing revision the request is based on.
Latest Revision
The latest drawing revision, when it differs from the Drawing Revision.
Requested Action
What is being asked for: describe the problem and the change requested. Always state what the part should be versus what it is, with sheet number and zone if applicable.
Item
The item (part number) the change is for. Selecting an item also filters the Next Lvl Assy, Serial # and LOT # lists.
Item Desc
The description of the selected item.
Next Lvl Assy
The next-level assembly that uses the item. The list shows the job items that use the selected Item.
Next Assy Desc
The description of the next-level assembly.
Vendor
The vendor involved in the change, if any.
Vendor Name
The name of the selected vendor.
Priority
How urgent the change is.

Change Request Fields

Dept
The department where the change is needed.
Dept Description
The name of the selected department.
Work Center
The work center where the change is needed.
WC Description
The name of the selected work center.
Reported By
Who reported or requested the change (free text).
Due Date
The date the change should be completed by.
Initial Change
The type of change requested. Selecting it ticks the Requirement checkboxes that apply (see the table); you can then change the checkboxes by hand.
Req: Costing, Documentation, Tool/Machine, Process, Material
Which reviews the change needs: Costing, Documentation, Tool/Machine, Process and Material. Select each one that applies.
General Note
Any other information about the request.

Additional Fields

Serial #
The serial number of the affected unit. The list shows the serial numbers of the selected Item; it is empty for items that aren't serial-tracked. You can also type a value.
LOT #
The lot of the affected material. The list shows the lots of the selected Item; it is empty for items that aren't lot-tracked. You can also type a value.
Top Level PN
The top-level part number the affected part goes into.
Sub Assembly
The sub-assembly the affected part belongs to.

Quality

SOX Impacted
Select if the change affects Sarbanes-Oxley (SOX) controls.
Hold On PO
Select if the purchase order is on hold because of this CMR.
Authorization For Supplier To Ship
Select when the supplier is authorized to ship.
Reason Code
Why the CMR was raised. The codes are the same as on QC MRRs.
Cause Code
The cause found for the problem. The codes are the same as on QC MRRs.
QC Disposition
Quality's decision on the affected material or parts.
Reviewer ID / Reviewer (Quality)
The Quality reviewer for this CMR.
QC RCA Notes
Quality's root cause analysis notes.

Engineering

EO Num
The engineering order number for the change.
MDL
The MDL reference for the change.
Engineering Disposition
Engineering's decision on the affected material or parts.
Reviewer ID / Reviewer (Engineering)
The Engineering reviewer for this CMR.
Internal Review Date
The date of Engineering's internal review.
Eng RCA Notes
Engineering's root cause analysis notes.

Implementation

Planning
Planning's part of the change. Select the checkbox when Planning is done, and pick the Planning reviewer in Reviewer ID.
Purchasing
Purchasing's part of the change. Select the checkbox when Purchasing is done, and pick the Purchasing reviewer in Reviewer ID.
CM
Configuration Management's part of the change. Select the checkbox when CM is done, and pick the CM reviewer in Reviewer ID.
Closed
Select to close the CMR. Clear it to reopen the CMR.
Close Date
The date the CMR was closed.
Closed By
The user who closed the CMR.
